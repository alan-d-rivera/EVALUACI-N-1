# Evaluación 1 - Herramientas Computacionales 2

Este repositorio contiene el análisis elástico lineal y la nota técnica para una viga simplemente apoyada con carga puntual centrada.

## Estructura del Repositorio
- `data/`: Datos originales de entrada (`datos_viga.csv` y `parametros_viga.xlsx`).
- `analysis/`: Archivos de procesamiento y cálculo de deflexiones.
- `figures/`: Gráfica generada (`carga_deflexion.png`).
- `report/`: Código fuente LaTeX (`main.tex`), referencias (`referencias.bib`) y PDF final.
- `USO_IA.md`: Declaración del uso de Inteligencia Artificial.

## Instrucciones de Reproducción
1. Revisar los parámetros en `data/parametros_viga.xlsx`.
2. Abrir `analysis/analisis_viga.xlsx` para seguir la secuencia de cálculo de $I$ y $\delta_{\text{teo}}$.
3. Compilar `report/main.tex` en un entorno LaTeX (como Overleaf) para generar el PDF técnico.
